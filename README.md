###  Установка через WSL (Linux)
! Установка WSL может привести к поломке других виртуальных машин (VMware, VirtualBox и т.д.).

1. Установите Ubuntu (через PowerShell от имени администратора):
   ```wsl --install -d Ubuntu-22.04```

2. Перезагрузите ваш ПК, после перезагрузки зайдите в wsl и продолжите настройки

3. Выполните команду установки из под wsl:
   ```curl -sSfL https://github.com/felixhghg/Felok/raw/refs/heads/master/install-wsl | bash```

---

### Установка на Windows
1. Скачайте архив: Code -> "Download ZIP".
2. Распакуйте архив в любую папку.
3. Установите Python, если он еще не установлен.
4. Запустите файл командой:
   ```python main.py```
