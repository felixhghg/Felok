###  Installation via WSL (Linux)
! WARNING: Installing WSL may cause other virtual machines (VMware, VirtualBox, etc.) to malfunction.

1. Install Ubuntu (via PowerShell as Administrator):
   ```wsl --install -d Ubuntu-22.04```

2. Restart your PC. After rebooting, enter WSL to complete the setup.

3. Run the installation command inside WSL:
   ```curl -sSfL https://github.com/felixhghg/Felok/raw/refs/heads/master/install-wsl | bash```

---

###  Installation on Windows
1. Download the archive: Click "Code" -> "Download ZIP".
2. Extract the archive to any folder.
3. Install Python if it is not already installed.
4. Run the project using the following command:
   ```python main.py```
